# mason-cyber
Cyber Range that could be run on a local server to facilitate student learning environments.

## Project Scope
- **Primary Infrastructure**: Proxmox VE on dedicated "extra server"
- **Extended Infrastructure**: Gaming PC fleet dual-boot capability for additional capacity during school hours
- **Access Method**: Web-based via Apache Guacamole + Cloudflare Tunnels for Chromebook compatibility
